* Edger

Seamlessly move through [[https://herdr.dev/][Herdr]]/[[https://tmux.app/][tmux]] panes & [[https://www.gnu.org/software/emacs/][Emacs]]/[[https://neovim.io/][Neovim]] splits. =alt-h/j/k/l= navigates between all splits as if it were one app.

Tabs grow rightward; workspaces grow downward. When you hit the horizontal edge, =alt-h/l= will navigate to the neighbouring Herd/tmux tab. And when you hit the vertical edge, =alt-j/k= will navigate to the neighbouring Herdr workspace or tmux session. Oh, and if you're on last tab, force through with double =alt-l= to create a new Herdr/Tmux tab. Same story if you're on the last workspace/session: force through with double =alt-j= to create a new Herdr workspace or tmux session.

Modifer =alt= can be customized to =ctrl= or =ctrl+alt=.

| Key | Direction | Herdr pane edge    | tmux pane edge               |
|-----+-----------+--------------------+------------------------------|
| h   | left      | previous tab       | previous window              |
| j   | down      | next workspace     | next session                |
| k   | up        | previous workspace | previous session            |
| l   | right     | next tab           | next window                  |

When a Herdr or tmux pane is zoomed, moving toward a neighboring split unzooms it first. At a split edge, zoom stays on while Edger follows the usual tab or workspace navigation.

Also! =alt-i= will split vertically, =alt-u= will split horizontally, and =alt-w= will close the current window/pane. All keys customizable.

** Emacs

Emacs 31 can install this repository with =package-vc= through =use-package=. =edger-setup= enables a global minor mode with all eleven bindings; no manual =:bind= list is needed. Pick one complete setup:

#+begin_src emacs-lisp
;; Alt (default): M-h/j/k/l, M-H/J/K/L, M-u/i/w
(use-package edger
  :vc (:url "https://github.com/suderman/edger" :lisp-dir "emacs" :rev :newest)
  :demand t
  :config (edger-setup))
#+end_src

#+begin_src emacs-lisp
;; Ctrl: C-h/j/k/l, C-S-h/j/k/l, C-u/i/w
(use-package edger
  :vc (:url "https://github.com/suderman/edger" :lisp-dir "emacs" :rev :newest)
  :demand t
  :config (edger-setup "C"))
#+end_src

#+begin_src emacs-lisp
;; Ctrl+Alt with custom split/close letters: C-M-h/j/k/l,
;; C-M-S-h/j/k/l, C-M-s/v/q
(use-package edger
  :vc (:url "https://github.com/suderman/edger" :lisp-dir "emacs" :rev :newest)
  :demand t
  :config (edger-setup "C-M" "s" "v" "q"))
#+end_src

The last three arguments to =edger-setup= replace =u=, =i=, and =w= in any setup. Calling it again removes the previous Edger bindings. Close removes a window, then a tab-bar tab, then the frame when another frame on the same display can take focus, and only then the multiplexer pane. Emacs represents Ctrl+Shift+h as =C-S-h=; plain =C-H= may collapse to =C-h= in terminals. =edger-executable= overrides the bundled script if needed. A standalone terminal Emacs gets its pane identity from =HERDR_PANE_ID= or =TMUX_PANE=. If a graphical daemon serves terminal clients, pass the pane identity as frame parameters with =emacsclient --tty -F=. Use =edger-herdr-pane-id= and =edger-herdr-socket-path= for Herdr, or =edger-tmux-pane-id= and =edger-tmux-socket= for tmux. The socket values come from =$HERDR_SOCKET_PATH= and =$TMUX=, respectively. Graphical frames stay within Emacs.

** Neovim

Choose one lazy.nvim entry. Each maps navigation, shifted resizing, and split/close keys:

#+begin_src lua
-- Alt (default): <M-h/j/k/l>, <M-H/J/K/L>, <M-u/i/w>
{ "suderman/edger", opts = {} }

-- Ctrl: <C-h/j/k/l>, <C-H/J/K/L>, <C-u/i/w>
{ "suderman/edger", opts = { modifier = "C" } }

-- Ctrl+Alt with custom split/close letters: <C-M-h/j/k/l>,
-- <C-M-H/J/K/L>, <C-M-s/v/q>
{ "suderman/edger", opts = { modifier = "C-M", actions = { horizontal = "s", vertical = "v", close = "q" } } }
#+end_src

The plugin maps normal-mode keys using the chosen modifier. Shifted direction keys resize; action letters split or close windows. It creates =:EdgerLeft/Down/Up/Right=, =:EdgerResizeLeft/Down/Up/Right=, =:EdgerHorizontal=, =:EdgerVertical=, and =:EdgerClose=. Set =opts.actions = { horizontal = "s", vertical = "v", close = "q" }= with any modifier to change action letters, or =opts.keymaps = false= to bind the commands yourself. Set =opts.bin= to use a different executable. Without lazy.nvim, add this repository to =runtimepath= and call =require("edger").setup()=.

** Herdr

Install the plugin, then put this keymap in =~/.config/herdr/config.toml=:

#+begin_src sh
herdr plugin install suderman/edger
#+end_src

#+begin_src toml
[keys]
focus_pane_left = "prefix+h"
focus_pane_down = "prefix+j"
focus_pane_up = "prefix+k"
focus_pane_right = "prefix+l"
split_horizontal = "prefix+u"
split_vertical = "prefix+i"
command = [
  { key = "alt+h", type = "plugin_action", command = "edger.left" },
  { key = "alt+j", type = "plugin_action", command = "edger.down" },
  { key = "alt+k", type = "plugin_action", command = "edger.up" },
  { key = "alt+l", type = "plugin_action", command = "edger.right" },
  { key = "alt+shift+h", type = "plugin_action", command = "edger.resize-left" },
  { key = "alt+shift+j", type = "plugin_action", command = "edger.resize-down" },
  { key = "alt+shift+k", type = "plugin_action", command = "edger.resize-up" },
  { key = "alt+shift+l", type = "plugin_action", command = "edger.resize-right" },
  { key = "alt+u", type = "plugin_action", command = "edger.horizontal" },
  { key = "alt+i", type = "plugin_action", command = "edger.vertical" },
  { key = "alt+w", type = "plugin_action", command = "edger.close" },
]
#+end_src

The prefix keys keep direct pane movement and splits available when an editor has focus. Herdr does not let a plugin register a keymap; its config binds each action separately. To configure the modifier and action letters in Nix, generate the eleven shell bindings as in this example module:

#+begin_src nix
{lib, ...}: let
  edger = "/absolute/path/to/edger/bin/edger";
  modifier = "alt"; # or "ctrl", "ctrl+alt"
  binds.direction = {
    left = "h";
    down = "j";
    up = "k";
    right = "l";
  };
  binds.action = {
    horizontal = "u";
    vertical = "i";
    close = "w";
  };
in {
  programs.herdr.settings.keys.command =
    lib.mapAttrsToList (direction: letter: {
      key = "${modifier}+${letter}";
      type = "shell";
      command = "${edger} ${direction} ${modifier}+${letter}";
    }) binds.direction
    ++ lib.mapAttrsToList (direction: letter: {
      key = "${modifier}+shift+${letter}";
      type = "shell";
      command = "${edger} resize ${direction} ${modifier}+shift+${letter}";
    }) binds.direction
    ++ lib.mapAttrsToList (action: letter: {
      key = "${modifier}+${letter}";
      type = "shell";
      command = "${edger} ${action} ${modifier}+${letter}";
    }) binds.action;
}
#+end_src

In plain TOML, replace the Alt =command= array with your own eleven shell entries when changing keys. For example, one entry in that array would be:

#+begin_src toml
[keys]
command = [
  { key = "ctrl+alt+s", type = "shell", command = "/absolute/path/to/edger/bin/edger horizontal ctrl+alt+s" },
]
#+end_src

** Herdr app

The Herdr desktop app (=herdr-app=, with Herdr Core =hc=) uses the mod in =herdr-app/mods/edger= instead of the TUI plugin. Both can run at once. Link the folder itself, not its files one by one, since the mod imports =./edges.js=:

#+begin_src sh
ln -s /absolute/path/to/edger/herdr-app/mods/edger ~/.config/herdr-app/mods/edger
herdr-app check ~/.config/herdr-app/mods/edger
herdr-app do mod.open --name edger
#+end_src

A mod gets key commands only while it is shown, and Herdr's own layouts take no new blocks. =mod.open= shows Edger as a frameless 2 px window in the top-left corner that the app reopens with that layout on every start. Run it once for each layout you use; running it again closes the window. A personal layout can show it as a float instead: ={"id": "edger", "content": {"mod": "edger"}, "edge": "bottom", "align": "end"}= in the root's =floating= list. While no copy is shown, the keys fail with an "unknown command" notice. If two copies are shown, only the one that started last acts.

Then bind the keys in =~/.config/herdr-app/keys.json=:

#+begin_src json
{
  "global": {
    "alt-h": "edger.left",
    "alt-j": "edger.down",
    "alt-k": "edger.up",
    "alt-l": "edger.right",
    "alt-u": "edger.horizontal",
    "alt-i": "edger.vertical",
    "alt-w": "edger.close",
    "alt-shift-h": "edger.resize-left",
    "alt-shift-j": "edger.resize-down",
    "alt-shift-k": "edger.resize-up",
    "alt-shift-l": "edger.resize-right"
  }
}
#+end_src

When Emacs or Neovim runs in the focused terminal, the mod types the key into it, by default Alt (and Shift for resizing) and the action's letter, as the bytes a terminal sends without the kitty keyboard protocol. =hc keys= suits agents: it types only after nobody has typed in the terminal for 3 s, so a key pressed right after typing would wait that long. The mod's =type= helper instead attaches to the terminal through =hc connect=, as the app does, types the key's bytes and detaches; it needs Bash, coreutils, =hc= and =jq=. It attaches as a returning viewer and sends the bytes as automatic input, so it never becomes the viewer whose size and colors the terminal follows. Keys are typed one at a time, in order. If the helper cannot attach, the mod falls back to =hc keys=. For other keys, name the key to send after a colon: ="ctrl-alt-h": "edger.left:ctrl+alt+h"=. At its last window in that direction, or with nothing left to close, the editor runs =edger cross=, which sets the label =edger= on its own Core terminal. The mod acts on that label only for the terminal it has just sent the same key to, within 1.5 s, and only while that terminal still has focus. Another Herdr window on the same Core, or an old label, therefore moves nothing. Labels reach the app through Core, so an editor on another machine works the same way, provided that machine has Edger and =hc=.

Emacs and Neovim avoid that round trip. After each command each publishes the Edger keys it would handle itself in its selected window as the label =edger.local= (=hjkl= for a window that way, =HJKL= for a divider on that axis, =w= for something to close, then a count of Edger commands), over one long-lived =hc connect= per Core instead of a process per update (Emacs: =post-command-hook=, =edger-hc-executable= names the command; Neovim: =SafeState=, =opts.hc=). When Emacs would not use a key, the mod acts at once, as for a shell. The app's copy of a label lags Core's by 150 ms or more, so unless that copy says Emacs uses the key, the mod reads the label from Core (=hc get=, about 10 ms) before deciding, and while keys it sent are still unanswered by the count it lets Emacs decide. In app terminals both editors also send their crossing requests over that connection and skip clearing, so they start no processes. A daemon's =emacsclient --tty= frames find their terminal from the client's environment, so they need no frame parameters.

Otherwise the mod moves between panes, then tabs of the space (left/right) or spaces (up/down), and splits or closes the pane itself. Moving to a neighboring split clears zoom; at an edge zoom stays. Alt+w keeps the last pane of the last space. A double press at the last tab or space makes a tab, or a space on the same machine. The app gives key bindings no repeat flag, so a creation waits 120 ms and a further press of the same key in that time, as from a held key, cancels it. Resizing moves the nearest divider in that direction, after the pane if there is one, else before it, by 5% of its split, and stops with 5% left on either side. The mod reads the split tree and its weights from Core (=doc.get= on the "herdr-app" document, through =hc connect=, from the space's machine) and sets them with =layout.resize=. The app stores a change in Core about half a second later, so for 1.5 s after a resize the mod reuses the weights it set; a divider dragged with the mouse and then resized from the keyboard within that time jumps back.

*** Alt+Z prefix

The app's own multi-key bindings (=alt-z u=) wait one second with nothing on screen, and an unfinished one reaches the program. Bind ="alt-z": "edger.prefix"= instead, and remove any other =alt-z …= binding so the app does not wait for one. Alt+Z then opens a small list of the next keys and waits for one, with no time limit; Esc or any other key closes it. This is the way to split or zoom a Herdr pane while an editor has focus. Holding Alt for the second key works too.

The list comes from =edger.json= next to =keys.json=, as ={"prefix": {"u": "pane.split:down", "z": "pane.zoom", "{": {"command": "tab.move", "args": {"by": -1}, "label": "move tab left"}}}=: keys as =keys.json= spells them (=shift-d=), or the character typed (=?=, =]=); values as =keys.json= actions, with an optional =label=. Without the file, the mod uses a short default list.

** tmux

With TPM, put one of these in =~/.tmux.conf=. Options must come before the plugin entry:

#+begin_src tmux
# Alt (default): M-h/j/k/l, M-H/J/K/L, M-u/i/w
set -g @plugin 'suderman/edger'
#+end_src

#+begin_src tmux
# Ctrl: C-h/j/k/l, C-H/J/K/L, C-u/i/w
set -g @edger-key 'C'
set -g @plugin 'suderman/edger'
#+end_src

#+begin_src tmux
# Ctrl+Alt with custom action letters: C-M-h/j/k/l, C-M-H/J/K/L, C-M-s/v/q
set -g @edger-key 'C-M'
set -g @edger-horizontal-key 's'
set -g @edger-vertical-key 'v'
set -g @edger-close-key 'q'
set -g @plugin 'suderman/edger'
#+end_src

The plugin also maps shifted direction keys for resizing and =u/i/w= for split and close actions. Bind =prefix+u= to =split-window= and =prefix+i= to =split-window -h= to split a tmux pane even while an editor is focused. Override action letters with =@edger-horizontal-key=, =@edger-vertical-key=, and =@edger-close-key= before loading the plugin. For example, =set -g @edger-close-key 'q'= maps Alt+q by default. Up/down switches tmux sessions at a pane edge by default. Two down presses at the bottom create a new session. Session switching and creation affect the tmux client, not just its pane. Edger does not change border styles or show boundary messages. The bindings settle common presses inside tmux without starting a process: a key goes straight to Emacs or Vim when tmux reports it as the pane's foreground command, and a shell pane moves, resizes, or splits directly unless it is zoomed or at the edge. Edge crossings, zoomed panes, closing, and other foreground programs run the script, which matters where starting processes is slow, as on Android. Set =@edger-mappings= to =off= to supply your own bindings. Without TPM, run =edger.tmux= from your tmux configuration. Reload the plugin after changing its options.

** Terminal keys and CLI

Check that your terminal and multiplexer deliver the keys you picked. Traditional terminals can encode Ctrl+Alt as Escape followed by a control byte; Ctrl+h may collide with Backspace, and Ctrl+s may pause terminal output. Inspect a key with Emacs =M-x describe-key RET= or check a Neovim mapping with =:verbose nmap <C-h>=, then try it through Herdr or tmux. In one tested setup, Herdr =pane send-keys ctrl+alt+l= reached terminal Emacs =C-M-l=; tmux 3.6a sends =C-M-l= as ESC followed by Ctrl-L. Neither check proves what every physical keyboard sends.

The shared executable accepts =edger left|down|up|right=, =edger resize left|down|up|right=, and =edger horizontal|vertical|close= from multiplexer bindings. Editors invoke the matching =edger cross ...= operation when needed. In a Herdr app terminal (=HC_TERMINAL_ID= set, outside tmux and the TUI), =edger cross= only sets the Core label described above. You can pass an explicit forwarding key as the last argument, such as =edger left ctrl+h= for Herdr or =edger resize left M-H= for tmux. =EDGER_KEY_MODIFIER= changes the Herdr default; tmux bindings pass their exact key. =EDGER_BACKEND=, =HERDR_BIN_PATH=, and =TMUX_BIN_PATH= override backend or CLI selection. Set =EDGER_BOUNDARY_TIMEOUT_MS= (default 700) to change how long a confirmation stays armed, or =EDGER_CREATION_IDLE_MS= (default 400) to change the quiet period after rapid navigation. Edger keeps short-lived state in =${XDG_RUNTIME_DIR:-$HOME/.cache}/edger=, overridable with =EDGER_STATE_DIR=. Terminal protocols usually do not report key release. Edger ignores presses less than 120 ms apart while armed to reduce accidental creation on key repeat, but cannot guarantee whether a physical key was held. Editor-initiated tmux session switching resolves the client for its pane; it does not need the tmux key binding's environment.

The script needs Bash 5 and the active multiplexer CLI. The tmux plugin uses regex format matching (=#{m/r:...}=) and brace command blocks; tmux 3.6 and 3.8 are tested. Herdr also needs =jq=. tmux foreground detection reads =/proc= and falls back to =ps= where =/proc= is missing, such as on macOS. Edger adds no build step or daemon. Keep the editor integration, multiplexer plugin, and script on the same revision when updating. The Herdr app mod was tested with =herdr-app= 0.1.16 and =hc= 0.1.21. Run =tests/run.sh= for shell/Neovim checks (and the mod's logic, when =node= is installed) and =emacs --batch -Q -L emacs -l emacs/edger.el -l tests/edger-test.el -f ert-run-tests-batch-and-exit= for Emacs checks.
