* Edger

Edger moves with one press through Emacs or Neovim windows, Herdr or tmux panes, then existing tabs and workspaces. Left/right moves through tabs (tmux windows); up/down moves through workspaces (tmux sessions). At the rightmost tab or bottommost workspace, two same-direction presses within 700 ms create a new one. If you just navigated there, Edger waits until you stop pressing that direction for 400 ms before the first press can arm creation. Rapid presses at the edge restart that pause. Left/up stops at the first tab or workspace without creating anything. A successful move or different direction clears pending creation. Edger also resizes editor splits first, and splits or closes windows in the focused editor or multiplexer.

| Key | Direction | Herdr pane edge    | tmux pane edge               |
|-----+-----------+--------------------+------------------------------|
| h   | left      | previous tab       | previous window              |
| j   | down      | next workspace     | next session                |
| k   | up        | previous workspace | previous session            |
| l   | right     | next tab           | next window                  |

#+begin_src text
M-l  at a pane edge   -> switch to the next tab, if one exists
M-l  at the last tab -> stay put (pause first if you just navigated here)
M-l  again           -> create a tab to the right
#+end_src

Tabs grow rightward; workspaces grow downward. =M-j= uses the same creation rule at the bottom. =M-h= at the first tab and =M-k= at the first workspace stop without a message. Standalone editors without a multiplexer keep local-only navigation. Edger does not control desktop windows.

Alt+h/j/k/l navigates. Alt+Shift+h/j/k/l resizes a divider on the relevant axis, starting in the editor and falling back to the multiplexer. Without a matching split, resizing does nothing. Alt+u splits below and Alt+i splits right. Alt+w closes the current editor window while multiple windows remain, then the current editor tab while multiple tabs remain. With one window in one tab, it closes the multiplexer pane. Closing the last pane closes its tab and, where applicable, its workspace or session. Edger leaves the last workspace or session intact. Use Ctrl or Ctrl+Alt instead of Alt if your terminal delivers those keys reliably; keep one modifier across all layers.

** Emacs

Emacs 31 can install this repository with =package-vc= through =use-package=. =edger-setup= enables a global minor mode with all eleven bindings; no manual =:bind= list is needed. Pick one complete setup:

#+begin_src emacs-lisp
;; Alt (default): M-h/j/k/l, M-H/J/K/L, M-u/i/w
(use-package edger
  :vc (:url "https://github.com/suderman/edger" :lisp-dir "emacs" :rev :newest)
  :demand t
  :config (edger-setup))
#+end_src

#+begin_src emacs-lisp
;; Ctrl: C-h/j/k/l, C-S-h/j/k/l, C-u/i/w
(use-package edger
  :vc (:url "https://github.com/suderman/edger" :lisp-dir "emacs" :rev :newest)
  :demand t
  :config (edger-setup "C"))
#+end_src

#+begin_src emacs-lisp
;; Ctrl+Alt with custom split/close letters: C-M-h/j/k/l,
;; C-M-S-h/j/k/l, C-M-s/v/q
(use-package edger
  :vc (:url "https://github.com/suderman/edger" :lisp-dir "emacs" :rev :newest)
  :demand t
  :config (edger-setup "C-M" "s" "v" "q"))
#+end_src

The last three arguments to =edger-setup= replace =u=, =i=, and =w= in any setup. Calling it again removes the previous Edger bindings. Emacs represents Ctrl+Shift+h as =C-S-h=; plain =C-H= may collapse to =C-h= in terminals. =edger-executable= overrides the bundled script if needed. A standalone terminal Emacs gets its pane identity from =HERDR_PANE_ID= or =TMUX_PANE=. If a graphical daemon serves terminal clients, pass the pane identity as frame parameters with =emacsclient --tty -F=. Use =edger-herdr-pane-id= and =edger-herdr-socket-path= for Herdr, or =edger-tmux-pane-id= and =edger-tmux-socket= for tmux. The socket values come from =$HERDR_SOCKET_PATH= and =$TMUX=, respectively. Graphical frames stay within Emacs.

** Neovim

Choose one lazy.nvim entry. Each maps navigation, shifted resizing, and split/close keys:

#+begin_src lua
-- Alt (default): <M-h/j/k/l>, <M-H/J/K/L>, <M-u/i/w>
{ "suderman/edger", opts = {} }

-- Ctrl: <C-h/j/k/l>, <C-H/J/K/L>, <C-u/i/w>
{ "suderman/edger", opts = { modifier = "C" } }

-- Ctrl+Alt with custom split/close letters: <C-M-h/j/k/l>,
-- <C-M-H/J/K/L>, <C-M-s/v/q>
{ "suderman/edger", opts = { modifier = "C-M", actions = { horizontal = "s", vertical = "v", close = "q" } } }
#+end_src

The plugin maps normal-mode keys using the chosen modifier. Shifted direction keys resize; action letters split or close windows. It creates =:EdgerLeft/Down/Up/Right=, =:EdgerResizeLeft/Down/Up/Right=, =:EdgerHorizontal=, =:EdgerVertical=, and =:EdgerClose=. Set =opts.actions = { horizontal = "s", vertical = "v", close = "q" }= with any modifier to change action letters, or =opts.keymaps = false= to bind the commands yourself. Set =opts.bin= to use a different executable. Without lazy.nvim, add this repository to =runtimepath= and call =require("edger").setup()=.

** Herdr

Install the plugin, then put this Alt keymap in =~/.config/herdr/config.toml=:

#+begin_src sh
herdr plugin install suderman/edger
#+end_src

#+begin_src toml
[keys]
focus_pane_left = "prefix+h"
focus_pane_down = "prefix+j"
focus_pane_up = "prefix+k"
focus_pane_right = "prefix+l"
split_horizontal = "prefix+u"
split_vertical = "prefix+i"
command = [
  { key = "alt+h", type = "plugin_action", command = "edger.left" },
  { key = "alt+j", type = "plugin_action", command = "edger.down" },
  { key = "alt+k", type = "plugin_action", command = "edger.up" },
  { key = "alt+l", type = "plugin_action", command = "edger.right" },
  { key = "alt+shift+h", type = "plugin_action", command = "edger.resize-left" },
  { key = "alt+shift+j", type = "plugin_action", command = "edger.resize-down" },
  { key = "alt+shift+k", type = "plugin_action", command = "edger.resize-up" },
  { key = "alt+shift+l", type = "plugin_action", command = "edger.resize-right" },
  { key = "alt+u", type = "plugin_action", command = "edger.horizontal" },
  { key = "alt+i", type = "plugin_action", command = "edger.vertical" },
  { key = "alt+w", type = "plugin_action", command = "edger.close" },
]
#+end_src

The prefix keys keep direct pane movement and splits available when an editor has focus. Herdr does not let a plugin register a keymap; its config binds each action separately. To configure the modifier and action letters in Nix, generate the eleven shell bindings as in the personal Herdr module:

#+begin_src nix
{lib, ...}: let
  edger = "/absolute/path/to/edger/bin/edger";
  modifier = "alt"; # or "ctrl", "ctrl+alt"
  binds.direction = {
    left = "h";
    down = "j";
    up = "k";
    right = "l";
  };
  binds.action = {
    horizontal = "u";
    vertical = "i";
    close = "w";
  };
in {
  programs.herdr.settings.keys.command =
    lib.mapAttrsToList (direction: letter: {
      key = "${modifier}+${letter}";
      type = "shell";
      command = "${edger} ${direction} ${modifier}+${letter}";
    }) binds.direction
    ++ lib.mapAttrsToList (direction: letter: {
      key = "${modifier}+shift+${letter}";
      type = "shell";
      command = "${edger} resize ${direction} ${modifier}+shift+${letter}";
    }) binds.direction
    ++ lib.mapAttrsToList (action: letter: {
      key = "${modifier}+${letter}";
      type = "shell";
      command = "${edger} ${action} ${modifier}+${letter}";
    }) binds.action;
}
#+end_src

The Nix example follows the personal Herdr module and renders all eleven bindings. Change =modifier= and =binds.action= to match the other integrations, and set =edger= to the executable in your checkout or package. It calls the CLI directly, so it does not require installing the Herdr plugin. The final =${key}= in each command forwards the actual chord into a focused editor. In plain TOML, replace the Alt =command= array with your own eleven shell entries when changing keys. For example, one entry in that array would be:

#+begin_src toml
[keys]
command = [
  { key = "ctrl+alt+s", type = "shell", command = "/absolute/path/to/edger/bin/edger horizontal ctrl+alt+s" },
]
#+end_src

Do not add another =command= array alongside the Alt one. Bind the same custom action letters in Emacs or Neovim. Ctrl+Shift key delivery depends on the terminal. Run =herdr server reload-config= after editing =config.toml=.

** tmux

With TPM, put one of these in =~/.tmux.conf=. Options must come before the plugin entry:

#+begin_src tmux
# Alt (default): M-h/j/k/l, M-H/J/K/L, M-u/i/w
set -g @plugin 'suderman/edger'
#+end_src

#+begin_src tmux
# Ctrl: C-h/j/k/l, C-H/J/K/L, C-u/i/w
set -g @edger-key 'C'
set -g @plugin 'suderman/edger'
#+end_src

#+begin_src tmux
# Ctrl+Alt with custom action letters: C-M-h/j/k/l, C-M-H/J/K/L, C-M-s/v/q
set -g @edger-key 'C-M'
set -g @edger-horizontal-key 's'
set -g @edger-vertical-key 'v'
set -g @edger-close-key 'q'
set -g @plugin 'suderman/edger'
#+end_src

The plugin also maps shifted direction keys for resizing and =u/i/w= for split and close actions. Bind =prefix+u= to =split-window= and =prefix+i= to =split-window -h= to split a tmux pane even while an editor is focused. Override action letters with =@edger-horizontal-key=, =@edger-vertical-key=, and =@edger-close-key= before loading the plugin. For example, =set -g @edger-close-key 'q'= maps Alt+q by default. Up/down switches tmux sessions at a pane edge by default. Two down presses at the bottom create a new session. Session switching and creation affect the tmux client, not just its pane. Edger does not change border styles or show boundary messages. Set =@edger-mappings= to =off= to supply your own bindings. Without TPM, run =edger.tmux= from your tmux configuration. Reload the plugin after changing its options.

** Terminal keys and CLI

Check that your terminal and multiplexer deliver the keys you picked. Traditional terminals can encode Ctrl+Alt as Escape followed by a control byte; Ctrl+h may collide with Backspace, and Ctrl+s may pause terminal output. Inspect a key with Emacs =M-x describe-key RET= or check a Neovim mapping with =:verbose nmap <C-h>=, then try it through Herdr or tmux. In one tested setup, Herdr =pane send-keys ctrl+alt+l= reached terminal Emacs =C-M-l=; tmux 3.6a sends =C-M-l= as ESC followed by Ctrl-L. Neither check proves what every physical keyboard sends.

The shared executable accepts =edger left|down|up|right=, =edger resize left|down|up|right=, and =edger horizontal|vertical|close= from multiplexer bindings. Editors invoke the matching =edger cross ...= operation when needed. You can pass an explicit forwarding key as the last argument, such as =edger left ctrl+h= for Herdr or =edger resize left M-H= for tmux. =EDGER_KEY_MODIFIER= changes the Herdr default; tmux bindings pass their exact key. =EDGER_BACKEND=, =HERDR_BIN_PATH=, and =TMUX_BIN_PATH= override backend or CLI selection. Set =EDGER_BOUNDARY_TIMEOUT_MS= (default 700) to change how long a confirmation stays armed, or =EDGER_CREATION_IDLE_MS= (default 400) to change the quiet period after rapid navigation. Edger keeps short-lived state in =${XDG_RUNTIME_DIR:-$HOME/.cache}/edger=, overridable with =EDGER_STATE_DIR=. Terminal protocols usually do not report key release. Edger ignores presses less than 120 ms apart while armed to reduce accidental creation on key repeat, but cannot guarantee whether a physical key was held. Editor-initiated tmux session switching resolves the client for its pane; it does not need the tmux key binding's environment.

The script needs Bash 5 and the active multiplexer CLI. Herdr also needs =jq=; tmux foreground detection uses =ps=. Edger adds no build step or daemon. Keep the editor integration, multiplexer plugin, and script on the same revision when updating. Run =tests/run.sh= for shell/Neovim checks and =emacs --batch -Q -L emacs -l emacs/edger.el -l tests/edger-test.el -f ert-run-tests-batch-and-exit= for Emacs checks.
